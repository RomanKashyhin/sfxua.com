# LayerLab — инструмент для настройки звука под видео

Рабочее название: **LayerLab** (поменяем, если не нравится).
Ветка: `tool/layerlab-ui`. Папка: `layerlab/` (в `_dev/` нельзя: она исключена из git).

## 1. Что это

Приложение на компьютер. Посередине — видео. По бокам — панели.
В панелях — ползунки, которые меняют **характер** звука прямо во время
проигрывания видео: двинул «Сила ветра» — ветер в эмбиенте стал сильнее,
двинул «Листва» — зашуршало больше листвы. Звук слушаешь сразу под картинкой.

Звук не один файл, а **лейеринг**: набор слоёв (ветер-низ, ветер-верх, порывы,
пыль, листва…). Ползунок — это не громкость одного слоя, а **макро**: одна ручка
тянет сразу несколько параметров нескольких слоёв (громкость, фильтр, скорость,
плотность, разброс питча).

Разбивку на слои делаешь ты. Я делаю инструмент, в который слои кладутся.

## 2. Из чего состоит

### 2.1. Экран

```
┌───────────────┬────────────────────────────┬───────────────┐
│ СЛОИ          │                            │ ПОЛЗУНКИ      │
│               │                            │               │
│ [Эмбиент]     │         ВИДЕО              │ Сила ветра ─●─│
│ [Шаги]        │                            │ Пыль       ──●│
│ [Удары]       │                            │ Листва     ●──│
│               │                            │ Даль/близь ─●─│
│ ветер-низ  ▮▮ │                            │               │
│ ветер-верх ▮  │  ▶ ⏸  00:12.40 / 01:30.00  │ [A] [B] сброс │
│ порывы     ▮▮▮│  ━━━━━━●━━━━━━━━━━━━━━━━━  │ пресеты ▾     │
│ пыль       ▮  │  [loop ◁ ▷]                │               │
│ + слой        │                            │ мастер ───●─  │
└───────────────┴────────────────────────────┴───────────────┘
```

- **Центр** — видео, play/pause, таймкод, скраб, A-B луп (крутить один кусок
  сцены по кругу, пока настраиваешь).
- **Слева** — наборы слоёв (вкладки: Эмбиент, Шаги, Удары…) и сами слои
  выбранного набора: имя, индикатор уровня, mute/solo, своя громкость.
- **Справа** — макро-ползунки выбранного набора. Для эмбиента свои, для шагов
  свои. Кнопки A/B (сравнить две настройки), сброс, пресеты.
- **Низ** (позже) — таймлайн с маркерами: где шаг, где удар, автоматизация
  ползунков по времени.

### 2.2. Два типа слоёв

| Тип | Пример | Как играет |
|---|---|---|
| **Петля (loop)** | ветер, пыль, гул, листва | крутится постоянно, макросы меняют громкость/фильтр/скорость |
| **Ван-шот (one-shot)** | шаг, удар, хруст | запускается по событию: клик, клавиша, маркер на таймлайне; из пула вариантов (round-robin), случайный питч/громкость |

### 2.3. Макро-ползунок = карта влияния

Один ползунок описывается так: имя, диапазон, значение по умолчанию и список
«что он тянет». Пример для «Сила ветра» (0…100):

| Слой | Параметр | 0 → 100 |
|---|---|---|
| ветер-низ | громкость | −12 dB → 0 dB |
| ветер-верх | громкость | −30 dB → −6 dB |
| ветер-верх | фильтр (срез) | 800 Hz → 6 kHz |
| порывы | плотность | 0 → 8 в минуту |
| листва | громкость | +0 → +4 dB (ветер шевелит листву) |

Такие карты задаются в JSON (или в UI через «привязать»). Карта с `"mode": "mul"`
не задаёт параметр, а домножает его относительно своего `from` — так «Даль / близко»
приглушает верха поверх того, что выставила «Сила ветра». У слоя есть `trim` (дБ):
подъём тихого файла до рабочего уровня, чтобы карты считались от нормального нуля. Это и есть
«характер» — он сидит в картах, а не в кнопке «громче».

### 2.4. Файл проекта

Один JSON рядом с видео и звуками:

```json
{
  "video": "scene01.mp4",
  "sets": [
    {
      "name": "Эмбиент",
      "layers": [
        { "id": "wind_low",  "file": "amb/wind_low.wav",  "mode": "loop" },
        { "id": "wind_high", "file": "amb/wind_high.wav", "mode": "loop" },
        { "id": "gusts",     "file": "amb/gust_*.wav",    "mode": "oneshot", "density": 4 },
        { "id": "leaves",    "file": "amb/leaves.wav",    "mode": "loop" }
      ],
      "macros": [
        { "id": "wind", "name": "Сила ветра", "default": 40,
          "map": [
            { "layer": "wind_low",  "param": "gain",   "from": -12, "to": 0 },
            { "layer": "wind_high", "param": "gain",   "from": -30, "to": -6 },
            { "layer": "wind_high", "param": "cutoff", "from": 800, "to": 6000 },
            { "layer": "gusts",     "param": "density","from": 0,   "to": 8 }
          ] }
      ]
    }
  ],
  "snapshots": { "A": { "wind": 40, "dust": 20 }, "B": { "wind": 75, "dust": 60 } }
}
```

## 3. На чём делать

**Рекомендация: веб-технологии (HTML + Web Audio API), обёрнутые в Electron.**

Почему:
- Видео — родной `<video>`, звук — Web Audio: граф узлов (источник → громкость
  → фильтр → панорама → шина → мастер) меняется в реальном времени без щелчков.
- UI (ползунки, панели) делается быстро и выглядит как мы захотим.
- **Первые этапы вообще без Electron** — просто страница в браузере. Я могу
  показывать её тебе в превью прямо из этой сессии, ты — открыть с телефона
  или второго компа по локальной сети. Electron добавляем, когда нужны
  папки на диске, drag-and-drop проектов и установка как «приложение».
- Сохранение/экспорт: `OfflineAudioContext` отрендерит микс в WAV без
  реального времени.

Альтернативы и почему нет:
- **Unity** — ты в нём живёшь, но видеоплеер + кастомный UI там тяжелее и
  медленнее итерируется. Зато потом карты макросов можно экспортировать в
  параметры твоей SFX Audio System / FMOD — это стоит заложить в формат JSON.
- **JUCE (C++)** — профессионально, но каждая правка UI — компиляция. Для
  инструмента «под себя» избыточно.
- **Python + Qt** — звук в реальном времени с низкой задержкой там больнее.

## 5. Что нужно от тебя

1. Примеры ползунков (скрины/референсы), о которых ты говорил.
2. Первый набор звуков: эмбиент или шаги. Уже разбитый на слои, с именами
   файлов, какой слой — петля, какой — ван-шот.
3. Для каждого ползунка — одна фраза: «что он должен делать с какими слоями».
   Таблицу влияния из 2.3 заполню я, ты потом подправишь на слух.

## 6. Удобства, которые закладываю сразу

- Колесо мыши над ползунком — точная подстройка; двойной клик — в дефолт.
- Горячие клавиши: пробел — play/pause, `[` `]` — границы лупа, `A`/`B` —
  снимки, цифры 1–9 — триггер ван-шотов.
- Ползунки крупные, чтобы можно было крутить и с тачскрина/телефона.
- Всё состояние в одном JSON — легко слать мне в чат, легко версионировать.

## 7. Риски

- Браузер не даёт звук до первого клика — первый play по кнопке, не авто.
- Синхронизация звука с видео: звук ведём от `video.currentTime`, при
  расхождении > 40 мс мягко подтягиваем.
- Длинные wav — память: декодируем один раз, храним в буферах.
